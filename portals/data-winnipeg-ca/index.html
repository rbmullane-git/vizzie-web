What it is

About City of Winnipeg Open Data

City of Winnipeg Open Data is the open-data portal for Canada, covering Manitoba. It runs on Socrata, Tyler Technologies' open-data platform. You can browse it directly at data.winnipeg.ca.

Licence profile

Can you reuse the data?

Licences here are declared per dataset via Per-dataset metadata via api/catalog/v1 (`license` field). A machine-readable summary of the licence mix isn't available yet, but Vizzie surfaces each dataset's declared licence (or notes when none is given) as you browse — remember that an undeclared licence is not the same as public-domain or free-to-use, so check before you reuse.
