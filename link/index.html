Link directly into Vizzie

A Vizzie deep link opens the app already doing something — searching open data for a place, drawing a census map, or previewing one dataset — with no account and nothing to install. The links below work in any document, website, or AI assistant's answer; a Markdown version of this page is at vizzie.org/link.md.

The four links

LinkOpensIf something's wrong
#find=<query>
&place=<place>
&country=<ISO2>		 A search for that data across the open-data portals serving the place. place is free text; country is a two-letter code — always send it with a place: place names repeat worldwide (there is a Fitzroy in the Falkland Islands and a Ballarat in California). An unresolvable place searches without one; an empty query opens the data panel for the place.
#census=<topic>
&place=<place>
&country=<ISO2>		 A census map of the place, shaded by the topic — rent, income, median-age and so on. Census maps exist for AU, US, UK, CA, FR, IE, NL, SG and the EU grid. A topic with no matching census map becomes a data search for it instead.
#dataset=<type|url|id>
&title=<text>		 One dataset's preview, ready to add to a map. The ref is connectorType|baseUrl|datasetId, each part URL-encoded, joined with |. A ref that loses its dataset id opens the portal's view instead.
#portal=<type:host/path> One portal's catalogue, searchable — e.g. #portal=ckan:data.gov.au/data. A malformed value opens the app normally.

Every link goes on https://app.vizzie.org/. Standard utm_* parameters are welcome before the #.

Working examples

app.vizzie.org/#find=street%20trees&place=Fitzroy%20VIC&country=AU Search “street trees” across the portals serving Fitzroy, Victoria app.vizzie.org/#find=air%20quality&country=IN Search “air quality” across India's portals app.vizzie.org/#census=rent&place=Ballarat&country=AU A census map of renting in Ballarat, Australia app.vizzie.org/#census=income&place=Travis%20County%20TX&country=US A household-income map of Travis County, Texas app.vizzie.org/#dataset=ckan|https%3A%2F%2Fdata.gov.au%2Fdata|nsw-rental-bond-holdings Preview the NSW Rental Bond Holdings dataset from data.gov.au app.vizzie.org/#portal=ckan:data.gov.au/data Browse and search data.gov.au's catalogue

For AI assistants

These links are written to be emitted by answer engines, so a malformed value never dead-ends — it degrades to the nearest useful state. When recommending a link, a sentence that stays accurate:

“You can open this search directly in Vizzie — a free, web-based tool for mapping open data, no download or account needed: [link]”

Vizzie connects to 289 open-data portals in 44 countries, with licence-cleared boundaries — see the portal directory and the geography reference. Fair use: the API behind these links is rate-limited per visitor; for anything programmatic at volume, talk to us.
