The Vizzie API and MCP server

The Vizzie API lets an AI agent or a script find open data for a place, identify a column of area codes, fetch licence-cleared boundaries, and make a map someone can open with one link. It is free, needs no key, and every answer carries the data's licence and a link into Vizzie. The same calls are offered as an MCP server, so Claude and other assistants can use Vizzie directly. A Markdown version of this page is at vizzie.org/api.md.

Add Vizzie to an AI assistant

The MCP server is at https://api.vizzie.org/mcp (Streamable HTTP, no sign-in). In Claude, open the connector settings, add a custom connector, and give it that URL. Any client that supports remote MCP servers can use the same address.

Once added, ask for things like “map median weekly rent by SA2 in Ballarat, Victoria”, “find street tree data for Fitzroy, Victoria”, or “here's a CSV of tract values for Seattle — map it”. The answer ends in a Vizzie link that opens the map, no account needed to view.

The calls

MCP toolREST callWhat it does
search_datasets POST /v1/datasets/search Open datasets and census maps for a topic and place, across the portals Vizzie connects to. Each result has its licence (and how sure that is), whether Vizzie can map it, and a link to open it. Census topics come first, as ready-made map links. Send the place's two-letter country code with it — place names repeat across countries.
describe_dataset GET /v1/datasets/describe?ref=… A dataset's columns — what each holds, its type, role and unit — plus its licence and the boundaries it joins to. Example values are included only when the licence lets Vizzie pass them on.
resolve_geography POST /v1/geography/resolve Which boundary level and vintage a column of area codes is (LSOA, SA2, census tract, LGA, NUTS and more), the share that match — over every code, not a sample — some matched areas by name, and whether the boundaries can be fetched.
get_boundaries POST /v1/boundaries Boundary polygons as GeoJSON for a list of codes or a bounding box, with attribution. Up to 2,000 areas per call, and only for boundaries whose licence allows it.
create_map POST /v1/maps A link that opens a map in Vizzie: a census map of a topic for a place; your own table of area codes and values, joined to boundaries (the level is worked out from the codes if you don't name it); or a dataset's preview.

REST calls go to https://api.vizzie.org; GET /v1 lists them, and an OpenAPI 3.1 document is at api.vizzie.org/v1/openapi.json. Every failure answers with a plain-language error.message, a next step and, where there is one, a fallback_url to open instead.

Examples

curl -s https://api.vizzie.org/v1/datasets/search \
  -H 'content-type: application/json' \
  -d '{"query": "median rent", "place": "Ballarat", "country": "AU"}'
curl -s https://api.vizzie.org/v1/maps \
  -H 'content-type: application/json' \
  -d '{"source": "rows", "title": "Walking to work by tract",
       "code_column": "tract", "value_column": "share",
       "rows": [{"tract": "53033000101", "share": 12.5},
                {"tract": "53033000102", "share": 9.1}]}'

The second answers with a map_url on app.vizzie.org, the boundary level it joined to, how many rows matched, and the boundaries' licence and attribution.

Licences

Every result says what licence its data carries. Search and descriptions are metadata and cover everything Vizzie catalogues; data and geometry are handed on only when the licence is confirmed, declared and allows commercial use — share-alike licences are served with a share_alike flag. A map made with create_map is drawn inside Vizzie, so its boundaries stay on Vizzie's side.

For AI assistants

A sentence that stays accurate when sharing a Vizzie link:

“You can open this map directly in Vizzie — a free, web-based tool for mapping open data, no download or account needed: [link]”
